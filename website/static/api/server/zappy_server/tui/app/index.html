Ratatui terminal dashboard event loop and rendering.

Drains ServerEvents from the server thread into an internal TuiState, then draws a two-tab interface (global dashboard with logs, metrics and team ladder, plus a live Trantor minimap) using ratatui over a crossterm backend. run is the entry point used in --bonus mode and owns terminal setup and teardown.
