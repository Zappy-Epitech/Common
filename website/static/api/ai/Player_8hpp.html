◆ directionToMovement()

MovementDirection directionToMovement ( int  soundDirection)

Maps a broadcast sound direction to the move that approaches it.

The direction is relative to the player's orientation: 1 is straight ahead, then clockwise (2 front-right, 3 right, ... 8 front-left). The forward hemisphere advances, the right side turns right, the left side turns left; repeated calls as fresh broadcasts arrive converge onto the sender.

Parameters
soundDirectionThe direction reported by the server, 1-8.
Returns
The movement that brings the player closer to the sender.
Exceptions
ZappyExceptionwith INVALID_DIRECTION if soundDirection is 0 (same tile, no movement) or outside 1-8.

◆ parseBroadcast()

BroadcastMessage parseBroadcast ( const std::string &  line)

Parses a server broadcast notification into its direction and text.

Accepts a line of the form "message &lt;k&gt;, &lt;text&gt;" (see RFC 8.2). A single trailing newline, if present, is stripped. The direction must be an integer in the range 0-8; the text is everything after the first ", " separator and may itself contain commas or be empty.

Parameters
lineThe raw notification line.
Returns
The decoded direction and text.
Exceptions
ZappyExceptionwith INVALID_BROADCAST if the prefix, direction, or separator is missing or the direction is out of range.

Extracts the level from a "&lt;verb&gt; &lt;level&gt;" broadcast.

Backs the team's broadcast vocabulary: "upgrade N" (come help me elevate from level N) and "stop N" (the level-N ritual is over). The text must be exactly the verb, a space, then a non-empty run of digits.

Parameters
textThe decoded broadcast body.
verbThe expected leading keyword (e.g. "upgrade" or "stop").
Returns
The level, or -1 if text does not match verb + " " + digits.
