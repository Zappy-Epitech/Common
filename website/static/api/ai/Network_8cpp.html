std::vector< std::string > splitCompleteLines ( std::string &  buffer)

Splits a byte buffer into complete, newline-terminated lines.

Server data arrives in arbitrary chunks that may contain several lines, a partial line, or both. This extracts every line up to and including its trailing '\n ', removing them from buffer. Any trailing bytes after the last newline (an incomplete line) are left in buffer for the next call.

Parameters
bufferThe accumulated inbound bytes; consumed lines are erased from it.
Returns
The complete lines found, in order, each keeping its trailing newline.
