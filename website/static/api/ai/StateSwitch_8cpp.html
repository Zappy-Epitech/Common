The target a ritual host advertises this tick (with anti-freeze fallback).

The host gathers toward target until it has waited gatherPatience ticks without filling the band, then falls back to minimum so a short-handed band still incants instead of freezing forever. Host-only: the patience counter (Player::_coopWaitTicks) advances only for the host, so band members never desync — they all read the host's single advertised value.

Parameters
targetThe desired band size (see playersTargetToUpgrade).
minimumThe elevation's hard minimum (see playersRequiredToUpgrade).
ticksWaitedTicks the host has waited short-handed.
gatherPatienceTicks to wait before falling back to the minimum.
Returns
target while gathering, minimum once patience elapses.

int coopHomingTileIndex ( const std::string &  lookResponse,
int  soundDirection

Finds the visible player tile to step onto when homing to a ritual host.

The sound bearing (1-8) is coarse and lagging, so a joiner near the host orbits the tile instead of landing on it. When the host is in view, Look gives its exact tile: this returns the nearest other visible player tile whose movement hemisphere (tileIndexToMovement) agrees with the sound bearing's (directionToMovement), so the joiner steps precisely toward the host and not toward an enemy walking the other way. Returns -1 when no agreeing player is visible (caller then falls back to the sound bearing), when no other player is in view, or when soundDirection is not in 1-8.

Parameters
lookResponseThe raw Look response line.
soundDirectionThe host's last sound bearing, 1-8 (0/other -> -1).
Returns
The field-of-view index to step toward, or -1.

Whether a stalled ritual host should abandon its rally.

A deficit-host (formed without the full stone set) can stall forever if the rare stones never arrive; without an escape it camps and fork-loops. This returns true once the host has waited ticksWaited >= coopPatience, so it aborts and goes back to gathering. A coopPatience of 0 disables abandoning (never give up).

Decides the next COOP action from the player's own perception.

The decision is driven by the player's Look (how many players share its tile), not by the lagging broadcast sound direction: once enough players are gathered on the tile the player must incant, even if the last sound direction it heard is stale and non-zero. Relying on the direction alone makes a joiner walk off the tile exactly when the host falls silent to incant, dooming the ritual.

Parameters
targetPlayers to gather before incanting – the band target advertised by the host (see playersTargetToUpgrade / advertisedTargetForHost), which may exceed the bare playersRequiredToUpgrade minimum.
playersOnTilePlayers on the current tile, self included (from Look).
callDirectionLatest sound direction of the call (0 = same tile).
Returns
COOP_INCANT if enough players are gathered, COOP_WAIT if on the ritual tile but short of players, COOP_MOVE otherwise.

Decides whether a ritual host should fork to grow the team.

A cooperative elevation only resolves when playersRequired players gather on the host's tile (see playersRequiredToUpgrade). When the host has waited patience ticks and its tile is still short of players, the team simply does not have enough bodies, so it lays an egg to add one. Forking is skipped for a solo elevation (playersRequired ≤ 1, no reinforcement needed) and while food is below forkFoodMin, since each Fork costs 42 ticks the player spends not eating.

Decides the next HUNT action for a max-level player.

A player capped at the top level can no longer elevate, so its only useful job is to disrupt the enemy by ejecting them. Because Look never reveals team membership and Eject pushes every co-located player, the hunter first challenges the tile with a team-tagged ping and only ejects once the ack window has elapsed with no friendly reply – never pushing a confirmed teammate.

Parameters
playersOnTilePlayers on the current tile, self included (from Look).
allyOnTileWhether a same-tile teammate ack was received since the ping.
pingedWhether the team challenge has already been broadcast.
ticksWaitedTicks elapsed since the challenge was broadcast.
ackWindowTicks to wait for an ack before deciding to eject.
Returns
HUNT_ROAM when alone or a teammate is present, HUNT_PING to challenge a freshly found group, HUNT_WAIT while the ack window is open, or HUNT_EJECT once it elapses with no friendly reply.

◆ directionToMovement()

MovementDirection directionToMovement ( int  soundDirection)

Maps a broadcast sound direction to the move that approaches it.

The direction is relative to the player's orientation: 1 is straight ahead, then clockwise (2 front-right, 3 right, ... 8 front-left). The forward hemisphere advances, the right side turns right, the left side turns left; repeated calls as fresh broadcasts arrive converge onto the sender.

Parameters
soundDirectionThe direction reported by the server, 1-8.
Returns
The movement that brings the player closer to the sender.
Exceptions
ZappyExceptionwith INVALID_DIRECTION if soundDirection is 0 (same tile, no movement) or outside 1-8.

Players a cooperative elevation should gather toward (not the bare minimum).

Keeping bands large and level-synchronized lets the min-4 rituals carry the whole band up together (an incantation elevates every same-level player on the tile). Returns 1 for the solo level 1, 0 for levels that cannot elevate, the per-level minimum for levels 2-3 (a cheap pair climb — forcing a 6-band this early just starves low players), and coopTarget (clamped up to the minimum) for levels 4-7, where the 6-band forms and rides 4->5 and 5->6 up to reach level 6 six-strong.

Parameters

coopTargetThe desired band size (e.g. Params::coopTargetPlayers).
Returns

Whether a player waiting on the ritual tile should eat food underfoot.

Camping 6 players on one tile risks starvation, which would pull members off the tile (SURVIVE) and undo the gather. When food has dipped below grazeFoodMin and there is food on the player's own tile (index 0), the player takes it without moving, topping up before the SURVIVE hard floor ever triggers. Underfoot-only: it never sends the player off the rally tile to forage.

Parameters
visibleTilesThe per-tile resource lists from the last Look.
foodThe player's current food count.
grazeFoodMinThe comfort floor below which to graze.
Returns
true to take food from the current tile this tick, false to hold.

Computes which stones must be dropped to satisfy the next elevation.

The elevation ritual reads the stones lying on the player's tile, not the ones held in the inventory, so before incanting the player must drop whatever the tile is still missing. This returns one Ressource entry per stone to drop (a stone needed twice appears twice), counting what is already on the tile so nothing is dropped in excess.

Parameters
levelThe player's current level (1-7); other values need no stones.
currentTileThe resources already on the player's tile (from Look).
Returns
The stones to drop, in elevation-cost order, to meet the tile cost.
