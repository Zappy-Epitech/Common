Detailed Description

Parses GUI protocol lines for one team's progress.

Tracked tokens: ``pnw`` (new player: id x y orient level team), ``plv``
(player level change), ``pfk`` (a player forked -> a new team slot),
``pdi`` (a player died), and ``seg`` (a team won).

True once our team has appeared and all its players are now dead.

this is a terminal state for the game just like a win.
