Detailed Description

Manages the TCP connection to the Zappy server.

Owns the socket and two buffers: an inbound queue of messages received from the server and an outbound queue of messages waiting to be sent. Polling, receiving and flushing are driven externally (see pollCheck and processSendQueue).
