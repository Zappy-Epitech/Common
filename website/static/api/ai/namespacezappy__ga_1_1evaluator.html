Detailed Description

Run one Zappy game per genome and turn the outcome into a fitness score.

Launches a headless server and ``clients_nb`` ``zappy_ai`` clients, observes the
game over the GUI protocol, and keeps the team topped up the whole game -- reaping
dead/failed clients and respawning toward a target that grows with every fork, so
forked eggs are hatched and the team stays full (as in a real run) -- then tears
every process down.

◆ evaluate_population_parallel()

zappy_ga.evaluator.evaluate_population_parallel (   genomes,
  cfg 
) 
Evaluate every genome, up to ``cfg.parallelism`` *games* concurrently.

Each genome is scored over ``cfg.repeats`` games. Those games are flattened
into one flat task list so the pool can run more than ``len(genomes)`` games
at once: games are timer-bound (they wait on the server's real-time ticks,
not the CPU), so we oversubscribe cores and let many sleep in parallel.
Scores are then averaged back per genome.
