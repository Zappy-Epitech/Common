int countPlayersOnTile ( const std::string &  lookResponse)

Counts the players standing on the current tile from a Look reply.

Only tile 0 (the player's own tile) is inspected; that tile always lists the player itself, so a lone player counts as one. This is how a ritual host knows whether enough teammates have gathered before it incants.

Parameters
lookResponseThe raw Look response line (see parseLook).
Returns
The number of player tokens on tile 0, or 0 if there is no tile.

Parses a server broadcast notification into its direction and text.

Accepts a line of the form "message &lt;k&gt;, &lt;text&gt;" (see RFC 8.2). A single trailing newline, if present, is stripped. The direction must be an integer in the range 0-8; the text is everything after the first ", " separator and may itself contain commas or be empty.

Extracts the level from a "&lt;verb&gt; &lt;level&gt;" broadcast.

Backs the team's broadcast vocabulary: "upgrade N" (come help me elevate from level N), "stop N" (the level-N ritual succeeded), and "abort N" (the host abandoned the level-N ritual). The text must be exactly the verb, a space, then a non-empty run of digits.

Parameters

Returns
The level, or -1 if text does not match verb + " " + digits.

◆ parseInventory()

const std::string &  res

Updates an inventory in place from a server Inventory response.

The server replies with a bracketed list of code quantity fields, one per resource, e.g. "[ l 0, d 0, s 0, m 0, p 0, t 0, f 10 ]". Brackets and commas are treated as separators; a recognised one-letter code consumes the following integer as its quantity. Unknown codes and malformed fields are skipped, and resources absent from res keep their previous value.

Parameters
inventoryThe inventory to overwrite with the reported quantities.
resThe raw response, e.g. "[ f 5, l 2, s 0 ]".

◆ parseLook()

std::vector< std::vector< Ressource > > parseLook ( const std::string &  res)

Parses a server Look response into per-tile resource lists.

The server replies with a bracketed, comma-separated list of tiles, each tile holding space-separated tokens (resources, players, ...). Tokens that are not resources (e.g. "player") are ignored; an empty tile yields an empty list.

Parameters
resThe raw response, e.g. "[ player, linemate, food sibur, ]".
Returns
One entry per tile, in response order, each listing the resources on that tile. Empty if no well-formed [...] block is present.

Extracts the single argument of a "&lt;verb&gt; &lt;arg&gt;" broadcast.

Backs the team-identification vocabulary used by max-level hunters: "ping &lt;team&gt;" (is anyone from <team> on my tile?) and "ack &lt;team&gt;" (yes, a <team> member is here). Only the first token after the verb is returned, so trailing garbage is ignored.
