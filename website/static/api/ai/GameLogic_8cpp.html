int parseConnectNbr ( const std::string &  res)

Parses a server Connect_nbr response into a slot count.

A trailing newline, if present, is stripped first. The remaining text must be non-empty and contain only decimal digits, so signs and whitespace are rejected.

Parameters
resThe raw response, e.g. "3\n".
Returns
The number of free team connection slots reported by the server.
Exceptions
ZappyExceptionwith INVALID_CONNECT_NBR if the response is empty or contains a non-digit character.

Updates an inventory in place from a server Inventory response.

Each space-separated token has the form name:quantity. Tokens without a colon are skipped, and an unrecognised resource name is reported on stdout and left out. Fields whose resource does not appear in res keep their previous value.

Parameters
inventoryThe inventory to overwrite with the reported quantities.
resThe raw response, e.g. "food:5 linemate:2 sibur:0".

◆ parseLook()

std::vector< std::vector< Ressource > > parseLook ( const std::string &  res)

Parses a server Look response into per-tile resource lists.

The server replies with a bracketed, comma-separated list of tiles, each tile holding space-separated tokens (resources, players, ...). Tokens that are not resources (e.g. "player") are ignored; an empty tile yields an empty list.

Parameters
resThe raw response, e.g. "[ player, linemate, food sibur, ]".
Returns
One entry per tile, in response order, each listing the resources on that tile. Empty if no well-formed [...] block is present.
