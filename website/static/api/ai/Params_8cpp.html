Params loadParamsFromFile ( const std::string &  path)

Loads tunable Params from a flat JSON file of integer values.

The file is a flat object such as {"foodSurviveMin": 14, "minFoodToUpgrade": 50, "forkPatience": 10, "huntAckWindow": 2}. Unknown keys are ignored; any key that is absent or whose value is not a valid integer keeps the field's default. A missing or unreadable file yields all defaults, so this never throws.
